LEARNING OBJECTIVES

Students learn Python data structures and type hints needed to build an AI application.

CORE CONCEPTS

Python list stores an ordered, mutable collection of items. A tuple is ordered but immutable. A dictionary stores key-value pairs, while a set stores unique values. A string represents text and supports operations such as strip(), split(), and lower().

JSON is a text format commonly used to exchange structured data between applications. Python's json module supports converting between JSON strings and Python objects.

A dataclass reduces boilerplate when defining data models. Type hints communicate the expected types of parameters and return values, helping developers understand interfaces and detect mistakes.

EXAMPLE

from dataclasses import dataclass

@dataclass
class Document:
    doc_id: str
    title: str
    content: str

def normalize_text(text: str) -> str:
    return text.strip()

APPLICATION TO STUDENT SECOND BRAIN

The project uses data models such as Document and DocumentChunk. Type hints help define tool inputs and outputs, while JSONL stores test cases and execution logs.

KEY TAKEAWAY

Choose data structures based on the data's behavior. Use dataclasses for simple structured records and type hints to make interfaces clearer.
