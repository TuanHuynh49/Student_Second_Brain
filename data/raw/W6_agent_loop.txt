LEARNING OBJECTIVES

Build an agent loop that reasons about a task, selects tools, observes results, and stops safely.

CORE CONCEPTS

An agent loop repeatedly selects an action, executes it, and examines the result until it can answer or must stop. In a ReAct-style pattern, the system alternates between reasoning, acting, and observing.

Tools should have clear names, descriptions, typed parameters, and predictable return values. The agent should parse tool requests safely and handle failures without terminating unexpectedly.

MAX_STEPS limits how many tool-execution steps the agent can perform. The project specifies a maximum of five steps. This prevents unbounded loops and controls resource use.

Tool errors should be returned in a consistent form, such as "Error: document not found." The agent can use that result to decide whether to try another permitted action or report failure.

Memory may preserve useful information across interactions. The system should distinguish temporary conversation state from durable knowledge saved to the document store.

APPLICATION TO STUDENT SECOND BRAIN

The agent may search for lesson-plan content, retrieve a document, summarize evidence, or save a note. It should stop when the task is complete or the step limit is reached.

KEY TAKEAWAY

A reliable agent needs controlled steps, safe action parsing, predictable tool results, and clear stopping conditions.
