LEARNING OBJECTIVES

Understand embeddings, vector similarity, and top-k retrieval.

CORE CONCEPTS

An embedding represents text as a numerical vector. Text with related meanings may have vectors that are close under a chosen similarity measure, depending on the embedding model.

Cosine similarity measures the angle between two nonzero vectors:

cosine_similarity(A, B) = (A dot B) / (norm(A) times norm(B))

A vector store keeps vectors and associated metadata and supports similarity searches. When a user asks a question, the system embeds the query and retrieves the most similar document chunks.

Top-k retrieval returns up to k candidates ranked by similarity. A larger k may improve coverage but can introduce irrelevant context and increase processing cost.

Embeddings and vector indexes must use compatible models and dimensions. When source documents change, their embeddings or index entries may need to be updated.

APPLICATION TO STUDENT SECOND BRAIN

Dense retrieval helps locate lesson-plan passages even when a question uses wording different from the source document.

KEY TAKEAWAY

Vector similarity is a relevance signal, not proof that a passage answers the question. The system must still check evidence and source metadata.
